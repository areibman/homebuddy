# Ten couch models

Ten different simplified 3D reconstructions inspired by IKEA product references. These are newly created approximations, not official IKEA downloadable models or manufacturing CAD. Dimensions and details are estimated. The original KIVIK is separate.

Each folder contains an editable Blender scene (.blend), a portable model (.glb), and a rendered preview (.png). Open the PNG previews without Blender. The GLB files contain the sofa only, in meters; the Blender scenes also include studio lighting and a camera. Procedural surface grain is available in Blender; GLB uses the base material colors and roughness.
