# Furniture reconstruction review

All ten products were compared with their exact original IKEA catalog photographs. Geometry, base colors, surface textures and exported glTF materials were revised; original reference photos are unchanged.

These are independent photographic reconstructions. Published overall dimensions are checked, while hidden construction, precise upholstery deformation, fabric scans, grain patterns and camera optics remain inferred.

Each model includes a Blender scene, portable GLB, generated preview, original product/photo URLs, per-item review and export validation. Nine solid models embed filtered ambient occlusion; the rug uses its embedded jute maps. All embedded images are stored inside the GLBs.

Browser viewer: neutral directional studio environment; camera matching per product; equal square comparison canvases; fresh asset hashes prevent cached older models.

Validation: all ten exported envelopes pass the configured 3 mm tolerance for published axes. LAUTERS width/depth describe the tripod base diameter, while its loose cord extends beyond that footprint. No studio lights or cameras are included in downloadable GLBs.
